# MandateGuard Roadmap

Short-term (v1.2):
- [ ] Policy hot-reload without restart
- [ ] Webhook notifications for denied transactions
- [ ] Slack/Telegram alerts for threshold breaches
- [ ] Dashboard for real-time spending visibility

Medium-term (v2.0):
- [ ] Multi-chain support: Bitcoin, Cosmos, Polkadot
- [ ] RBAC (role-based access control) for team policies
- [ ] Persistent audit log (PostgreSQL/SQLite)
- [ ] Policy-as-code: version-controlled policy files
- [ ] Integration with hardware wallets (Ledger/Trezor)

Long-term:
- [ ] Compliance reporting (SOC 2, PCI DSS templates)
- [ ] Marketplace for community policy templates
- [ ] Enterprise SSO integration
- [ ] Real-time anomaly detection (ML-based, post-enforcement)
